# PulseGuard | 社区用户沉默预警与运营策略 Agent

PulseGuard 是面向社区运营人员的用户沉默风险识别与运营决策原型。项目基于 Meta Kaggle 公开行为数据，构建风险队列、用户诊断、风险解释、运营建议和行动留痕闭环。

## 产品链路

运营人员进入工作台后，系统默认展示风险概率最高的前 20 名用户。运营人员可以按风险类型和处理状态筛选用户，进入详情查看行为指标、风险结论和关键影响因素，再生成运营建议并选择站内通知或邮件提醒。

“发送触达”和“标记已处理”是两个独立动作，分别记录用户是否已被联系，以及本次运营任务是否完成。

## 核心功能

- 风险队列：按风险概率降序展示重点用户
- 风险类型筛选：活跃下降型、嵌入不足型、参与动量不足型等
- 处理状态筛选：待处理、已触达、已处理
- 用户诊断：查看用户近期和历史行为指标
- 风险解释：展示模型关注的行为因素及贡献方向
- 运营建议：生成可供运营人员复核的干预策略
- 行动留痕：记录触达渠道和处理状态

## 数据与评测

- 数据来源：Meta Kaggle 公开行为数据
- 用户规模：1,000 名匿名用户
- 用户月度记录：62,471 条
- 验证方式：时间留出验证
- ROC AUC：0.777
- 测试准确率：73.6%
- 召回率：82.3%

以上为离线模型验证结果，不代表真实线上运营效果。模型解释展示统计关联，不等同于因果结论。
